### Step 3: Deploy (Choose One)

**Option A: Using render.yaml (Easiest)**
1. In Render Dashboard: "New +" → "Web Service"
2. Connect your GitHub repo
3. Render auto-detects render.yaml
4. Review and deploy (all settings pre-configured)

**Option B: Manual Setup**
1. Create MySQL database first (2-3 minutes)
   - Database: `administration_suite`
   - User: `admin_user`

   - Connect GitHub repo
   - Choose Docker runtime
   - Dockerfile: `./Dockerfile`

3. Get database credentials and add to Web Service environment

- Wait for deployment (2-5 minutes)

- Complete initial setup:
  - School name
  - Admin account (name, PIN, account number)
  - Confirm database settings
  - Seed demo data: No (for production)

### Step 5: Secure & Test
- After setup, change `APP_ALLOW_SETUP=0` in environment
- Log in with admin credentials
- Test admin, staff, student portals

## 🎯 What Happens During Setup

When you visit `/setup.php` after deployment:

1. **Configuration Phase**
   - Enter school name
   - Enter organization name
   - Confirm database connection (auto-filled)
   - Select timezone (optional)
   - Choose demo data (yes/no)

2. **Admin Account Creation**
   - Enter account number (e.g., ADM-3001)
   - Enter full name
   - Enter PIN (secure, 4-6 digits)

3. **Initialization**
   - Database tables created
   - Admin user inserted
   - Configuration saved to `.env.runtime`
   - Session established

4. **Setup Locked**
   - Setup page automatically locked
   - To run setup again, must set `APP_ALLOW_SETUP=1`

---

## 🔐 Security Notes

1. **Setup Page Disabled**
   - After initial setup, APP_ALLOW_SETUP must be 0
   - Prevents unauthorized users from re-running setup
   - Do this before showing to clients

2. **Database Credentials**
   - Render generates strong password for database
   - Never put credentials in code
   - Environment variables handle all secrets

3. **HTTPS**
   - Render provides free SSL/TLS automatically
   - All traffic encrypted

4. **Backups**
   - MySQL backups enabled by default
   - Daily backups automatically
   - Can restore point-in-time

## 🆘 If Something Goes Wrong

1. **Check Render Logs**
   - Web Service → Logs tab
   - Look for error messages

2. **Common Issues**
   - Database not found: Verify credentials in Environment
   - Port binding error: Check port 80 available
   - Asset loading: Ensure paths are relative

3. **Reset & Retry**
   - Delete environment variable `APP_ALLOW_SETUP=0`
   - Redeploy
   - Visit setup.php again to reconfigure
