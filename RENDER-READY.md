## 🆘 If Something Goes Wrong

**Most Common Issues:**

1. **Database not found**
   - Solution: Verify DB_HOST in environment variables
   - Check Render MySQL service is "Live"

2. **Port binding error**
   - Solution: Render handles this, restart service
   - Check Docker build succeeded

3. **Setup page 404**
   - Solution: Change APP_ALLOW_SETUP=1
   - Redeploy service

4. **Slow page loads**
   - Solution: Upgrade to higher plan
   - Check database query performance

**See RENDER-DEPLOYMENT.md for complete troubleshooting guide.**
